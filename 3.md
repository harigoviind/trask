## 🎯 Scenario: Disk Analysis & Virtual Disk Simulation

You are working as a **Junior Linux System Administrator** in a production environment.

The infrastructure team has reported several storage-related concerns:

* The system disk structure is not clearly understood
* Root partition space usage is not properly monitored
* Large directories are consuming unknown amounts of space
* Disk identifiers (UUIDs) are not documented
* A safe testing environment is required without affecting real disks
* Engineers need to simulate additional storage without physical hardware

You are assigned to **analyze the current disk setup and create a virtual disk for safe experimentation**.

---

## ❓ Your Task

Perform a complete disk inspection and create a **virtual practice disk**, ensuring it behaves like a real storage device.

---

## 🛠️ Requirements (with Commands)

### 1. Inspect Disk Structure

```bash id="d1"
lsblk -f
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/1.png?raw=true)

**Answer:**

* Identify all disks and partitions
* Which partition is mounted as `/`?
* What filesystem types are used?

---

### 2. Analyze Filesystem Usage

```bash id="d2"
df -Th
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/2.png?raw=true)

**Answer:**

* What is the size of the root partition?
* How much space is used and available?
* What is the usage percentage?

---

### 3. Compare Directory Sizes

```bash id="d3"
du -sh /var /tmp /home
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/3.png?raw=true)

**Answer:**

* Which directory uses the most space?
* Why might `/var` grow significantly over time?

---

### 4. Identify Disk UUID

```bash id="d4"
sudo blkid
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/4.png?raw=true)

**Answer:**

* What is the UUID of the root partition?
* Why are UUIDs preferred over device names?

---

### 5. Create Virtual Disk

```bash id="d5"
dd if=/dev/zero of=~/disk.img bs=1M count=100
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/5.png?raw=true)

**Answer:**

* What does this command do?
* What is the size of the created disk file?

---

### 6. Attach Loop Device

```bash id="d6"
sudo losetup -fP ~/disk.img
sudo losetup -l
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/6.png?raw=true)

**Answer:**

* What loop device is created?
* What does a loop device represent?

---

### 7. Verify New Disk

```bash id="d7"
lsblk
```

![Command Output](https://github.com/hackmehub/screenshots-/blob/a5d5a7ef360552f7c1eb5718136becbf91291aa0/3/7.png?raw=true)

**Answer:**

* Can you identify the new loop device?
* What is its size?
* How is it displayed in the disk hierarchy?
