## 🎯 Scenario: Filesystem Navigation & Inode Analysis

You are working as a **Junior Linux System Administrator** in a DevOps team.

Developers have reported multiple issues while working on a shared Linux system:

* They are unable to clearly understand the directory structure
* Device files under `/dev` are confusing and undocumented
* CPU/system information is not easily accessible
* File tracking and metadata (inodes) are not understood
* Temporary files behave unpredictably
* Data written to certain system locations disappears unexpectedly

The senior administrator has assigned you to **investigate how the filesystem hierarchy works and how Linux manages files using inodes**.

---

## ❓ Your Task

Explore the system to understand:

* Directory structure (FHS)
* Device files and virtual filesystems
* File creation and inode tracking
* File metadata and system behavior
