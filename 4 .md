## 🎯 Scenario: Filesystem Creation & Mount Failure Investigation

You are working as a **Junior Linux System Administrator** in a production environment.

The infrastructure team attempted to set up a new storage space for application data using a virtual disk, but several issues were reported:

* The disk is attached but not usable
* Filesystem creation was incomplete or inconsistent
* Mounting fails or does not reflect expected storage
* Data written to the filesystem is not reliably accessible
* Engineers are unsure how to validate filesystem integrity
* UUID-based identification is not documented

You have been assigned to **create, mount, verify, and troubleshoot a fully functional filesystem** using a virtual disk.

---

## ❓ Your Task

Build a complete filesystem workflow and ensure it behaves like a reliable storage system.
